Note de mises à jour - 2026 - WebApp & MobileApp
section: 2026 · id: 32300116382354 · updated: 2026-10-19T16:54:04Z

Depuis le 15 décembre 2025, la solution est mise à jour toutes les 2 semaines. Tous les changements liés aux mises à jour de l'année 2026 seront renseignés ici.
Les nouveautés liées aux API sont détaillées sur une note de mise à jour dédiée.
R.2.23.0 - Production : 19 octobre 2026
  Pour des raisons d'organisation de nos releases, il n'y a pas de version R2.22 dont le contenu est dans la version R2.23. Préproduction le 6 octobre
      Génération PDF
          Le traitement des images lors de la compression du PDF a été
          optimisé afin de réduire le temps de génération des documents
          DSI et RFI. Le parcours utilisateur reste identique : le document
          est généré comme avant, et le PDF est produit plus rapidement.
          Points d'attention :
            Les images JPEG et PNG intégrées au document restent
            visuellement identiques à l'original, sans perte de qualité.
            Le gain est surtout perceptible sur les documents contenant
            plusieurs images.
    Corrections
          [Ticket #SFP-21474] L'utilisation du module fichier pour créer
          des flows spécifiques à partir d'un flow référentiel reprend
          désormais correctement les séquences de ce flow référentiel.
          [Ticket #2679] La génération du fichier .zip lors de l'export
          des photos ne produit plus aléatoirement un fichier qui ne
          s'ouvre pas.

  R.2.19.0 - Production : 7 septembre 2026
    En préproduction dès le 25 août 2026
      Formules
          La validation des formules a été renforcée pour
          les questions
          de type Formule, ainsi que pour les tableaux
          en ligne et en colonne. Les formules sont désormais validées
          avant sauvegarde ; une formule invalide est bloquée et un
          message d'erreur est affiché directement sous le champ concerné.
          Règles de saisie :
            Les paramètres d'une fonction doivent être séparés par un
            point-virgule ";", par exemple
            min(2;6).
            Les nombres décimaux respectent le format numérique configuré
            :
            1,5 en français et 1.5
            en anglais.
            La syntaxe et les références utilisées dans la formule sont
            contrôlées après une courte pause dans la saisie.
          Les valeurs sont ensuite normalisées lors du stockage en base
          de données, avec . comme séparateur décimal
          et sans espaces superflus. À l'affichage, elles sont
          automatiquement présentées selon le format numérique configuré
          pour l'utilisateur.
          Points d'attention :
            Le séparateur entre les paramètres d'une fonction est
            désormais ";".
            Le séparateur décimal dépend du format numérique configuré
            :
            "," en français et "."
            en anglais.
            Les formules existantes présentant une syntaxe incorrecte
            peuvent désormais être signalées lors de leur affichage ou
            de leur évaluation.
            Les contrôles sont réalisés avant sauvegarde afin d'éviter
            l'enregistrement de formules invalides.
            La documentation utilisateur devra être mise à jour afin
            de
            présenter les nouvelles règles de saisie des formules.
      Formulaires
          Lorsqu'une nouvelle rubrique est ajoutée à un formulaire
          disposant déjà de flows de navigation configurés, elle n'est
          désormais plus ajoutée automatiquement dans aucun flow existant.
          Les flows déjà configurés restent strictement inchangés.
          Le même comportement s'applique lors de la duplication d'une
          rubrique.
          Si l'utilisateur souhaite intégrer la nouvelle rubrique à un
          parcours, il doit l'ajouter manuellement depuis la configuration
          de la navigation.
          Points d'attention :
            Cette évolution ne modifie pas les flows déjà configurés.
            Après la création ou la duplication d'une rubrique, son ajout
            à la navigation d'un flow doit être réalisé manuellement
            si nécessaire.
            La possibilité de choisir directement, lors de la création
            d'une rubrique, le ou les flows auxquels elle doit appartenir
            reste hors périmètre et pourra faire l'objet d'une évolution
            dédiée.

          Il est désormais possible de définir une

          Prise de photo, le préparateur méthode peut

            champ

En préproduction dès le 24 mars 2026
      Téléchargements
            Au cours des prochaines semaines, le temps de téléchargement
            va être optimisé pour les flows
            partageant des ressources communes (formulaires
            présents dans plusieurs flows).
                Pour savoir quand votre organisation
                sera concernée par cette optimisation, vous pouvez
                contacter votre référent
                Siteflow.
            Les gains observés sont les
            suivants :
                  Temps de téléchargement
                :
                Réduction
                moyenne d'environ
                20%, pouvant atteindre jusqu'à 50% dans les cas les
                plus favorables.
                  Volume de données échangées
                :
                Réduction
                moyenne d'environ
                60%, avec un bénéfice particulièrement sensible sur
                les connexions lentes ou à faible débit.
            Concernant les flows partageant peu de ressources
            communes : les gains observés sont marginaux, et le temps
            de téléchargement restera donc sensiblement similaire.
            Un nouveau message d'erreur peut apparaître au moment de
            télécharger un flow et bloquer le téléchargement.
            Il permet d'identifier et d'aider à résoudre le cas suivant
            :
                Sur une tablette, le profil X a téléchargé des flows
                du projet P1.
                Le profil X a été déconnecté de la MobileApp alors
                que ses flows sont toujours téléchargés.
                Sur la même tablette, un profil Y se connecte à sa
                place mais il n'a pas accès au projet P1.
              Le profil Y tente de télécharger des flows du projet P2. 
                Le téléchargement était bloqué avec le message "un
                erreur est survenue lors du téléchargement".
            Désormais, le téléchargement sera bloqué en affichant le
            nouveau message d'erreur : il indique à l'opérateur de s'adresser
            à un administrateur en mesure de résoudre le problème.
Pour ce faire, il faudra :
                Soit ajouter le profil tablette Y au projet P1 depuis
                la WebApp.
                Soit se reconnecter avec le profil tablette X, vérifier
                que les données du projet P1 ont été renvoyées à
                la WebApp, supprimer les données locales et se reconnecter
                avec le profil tablette Y.
