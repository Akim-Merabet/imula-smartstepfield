Parameters: accounts and clients
This data should be configured by administrators before onboarding application end-users.
Accounts are managed by Siteflow administrators.
Application clients (clients of Siteflow client company) are created and managed by client administrators. They are account-specific and are not shared within the organisation.
Dictionaries
Siteflow application allows to define the client company’s own data values for Families, Categories, Statuses, Custom Attributes.
The table below describes which objects these dictionaries applies to (called relatedObject in the API) and whether they are private within the account or shared across all accounts in the organisation.
