Library
Data are usually created within projects. Data created in the library are intended to be reused in projects.
Objects in the Library include : External Document, Form, Asset, Tag, Equipment, Risk.
External documents are PDF documents added to the library in order to be used in any project. In opposition to document generated by the Siteflow application in projects. External documents could also be added into a project directly without making them available in the library.
Resources
Resources encapsulate “Collaborators and tablets” items from the WebApp.
Collaborators include Users and Operators. Users have access to both the Siteflow WebApp and the MobileApp, while operators have only access to the MobileApp.
Shared Users are contributors who only have access to a small portion of the WebApp through an encrypted link sent out by email which allows them to perform limited actions.
Devices (generally meaning Android tablets) using the MobileApp are registered in the application beforehand.
Collaborators
Users and operators are collaborators who share the same properties. Users have additional properties that operators don't have:
Email address.
SSO identifier.
Access right.
Eligible access rights are : SIMPLE | NORMAL | ADVANCED | ADMINISTRATOR | GLOBAL_ADMINISTRATOR | SITEFLOW_ADMINISTRATOR.
Devices
Devices have a "state" property which could have the following values : ACTIVATED | DEACTIVATED | BROKEN | CRASHED | IN_MAINTENANCE.
